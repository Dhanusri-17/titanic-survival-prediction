# Titanic Survival Prediction 

Predicts whether a Titanic passenger survived using Machine Learning.

## About the Project
- Used real Titanic passenger data from Kaggle
- Cleaned missing data and prepared features
- Trained a Random Forest Classifier model
- Achieved 72% accuracy on test data

## Tools and Technologies
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Dataset
- Source: Kaggle Titanic Competition
- 891 passenger records
- Features used: Pclass, Sex, Age, SibSp, Parch, Fare

## How to Run
1. Clone this repository
2. Open titanic_model.ipynb in Jupyter Notebook
3. Run all cells from top to bottom

## Result
Model Accuracy: 72%
